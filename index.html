Три шага до результата

Запуск в Telegram-боте или прямое подключение через REST API для ваших скриптов, CRM и сервисов.

01

Получите ключ или баланс

Откройте бота @OasisDigitalro_bot для проверки через чат. Для интеграции по API администратор выдаёт ключ формата OASIS-IO-... с нужным лимитом запросов и скоростью.

02

Отправьте запрос

Передайте цель в параметре q на /api/v1/search (GET или POST) с заголовком X-API-Key — система сама определит тип запроса (телефон, Telegram, email, авто, IP, ФИО).

03

Получите JSON и веб-отчёт

В ответе вернётся структурированный JSON со всеми найденными полями, report_id и готовая ссылка web_report на интерактивный веб-отчёт.

РАЗРАБОТЧИКАМ · REST API v1

Документация Oasis Digital API

Прямой программный доступ к поисковому движку Oasis Digital для интеграции в боты, панели и аналитические скрипты.

Спецификация эндпоинта REST API v1
GET / POST https://listopadov-search-1.onrender.com/api/v1/search
Авторизация и ключ

Ключи выдаются в формате OASIS-IO-.... Передавайте их в заголовке X-API-Key: OASIS-IO-... или Authorization: Bearer OASIS-IO-....

• Лимит скорости (req/min) и квота запросов задаются индивидуально для каждого ключа.

Параметры и заголовки
X-API-Key Обязательно
Ключ доступа OASIS-IO-...
q Обязательно
Поисковый запрос: телефон, @username, TG ID, email, VIN, госномер, IP или ФИО.
Коды статусов
200 — Успешный поиск
401 — Неверный / отозван ключ
429 — Лимит скорости / квоты
503 — API временно отключён

                    ВОПРОСЫ И ОТВЕТЫ
                

                
Частые вопросы

                

                    Ответы на частые вопросы о поиске, ключах REST API и отчётах.
                

            


            

                

                    
                        Как получить API-ключ OASIS-IO-... и задать лимит?
                        
                    
                    

                        Ключи создаются через админ-панель бота или команду администратора с указанием лимита запросов (включая безлимит) и лимита запросов в минуту. Связаться по выдаче доступа можно через @anodoxx или в боте @OasisDigitalro_bot.
                    

                


                

                    
                        Какие форматы запросов поддерживает REST API?
                        
                    
                    

                        В параметре q можно передавать номера телефонов, @username и ID Telegram, email, госномер авто, VIN, IP-адрес или ФИО. Система определяет тип автоматически.
                    

                


                

                    
                        Что означает статус 503 или 429 при обращении к API?
                        
                    
                    

                        503 означает, что доступ к API временно отключён администратором. 429 означает превышение лимита запросов в минуту или исчерпание выделенной квоты ключа.
